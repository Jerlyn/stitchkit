      Loading it on your machine

      1. Copy the file to a USB stick (top level, not inside a folder).
      2. Plug it into the machine and choose the USB icon.
      3. Pick the design and thread colors in the order shown.
      4. Clip connecting threads between shapes after each color.

      Privacy

      StitchKit converts your artwork entirely inside your browser. Your images and embroidery files are never uploaded to any server.

      We count page visits and downloads with GoatCounter. It uses no cookies and collects no personal information. File names and images are never included.

      Hoop size and recent settings are saved only on this device. If you install StitchKit as an app, a copy of the app itself is stored on your device so it works offline.

      How StitchKit works

      1. It reduces your art to a few thread colors.
      2. It traces each color's shapes and fills them with rows of stitches (a tatami fill), with an underlay so the fabric doesn't pucker.
      3. It writes a .PES file your machine can read from a USB stick.

      Everything happens on your device. Fine details under about 1.5 mm may stitch slightly rounded.
